# 1.6 리소스 축소(shrinkResources) 설정

Android Gradle Plugin 9 이상에서 릴리스 빌드에 `shrinkResources true`를 사용하면, 일부 광고 네트워크 SDK가 실행 중에 이름으로 찾는 리소스가 빌드 과정에서 제거될 수 있습니다. 제거된 리소스는 광고 초기화·노출 실패나 화면 깨짐으로 이어지므로, 앱 모듈에 keep 파일을 추가해 해당 리소스를 유지하도록 설정해 주세요.

#### 1. keep 파일 위치

```
app/                         ← 앱 모듈
└── src/main/res/raw/        ← raw 폴더가 없으면 새로 만듭니다
    └── keep.xml
```

* 이미 keep.xml이 있다면 `tools:keep` 값에 필요한 항목을 쉼표(,)로 이어 추가합니다.
* 추가·변경 후에는 반드시 clean 빌드하세요. 증분 빌드에서는 반영되지 않을 수 있습니다.

#### 2. 광고 네트워크별 항목

Pangle, Mintegral 등 AdMob 미디에이션 네트워크의 항목은 [버전 설정 가이드](https://cdn.fsn.co.kr/guide/sdk/adwhale/adwhale-mediation-guide\(ko\).html)에서 사용하는 네트워크를 선택하면 하단에 keep.xml 블록으로 표시됩니다.

#### 3. Cauly (앱 종료 광고 사용 시)

AdWhale 앱 종료 광고를 사용하고 Cauly가 포함된 경우, 종료 팝업의 버튼 이미지가 제거되어 버튼이 배경 없이 글자만 표시될 수 있습니다(광고 노출은 정상). 아래 항목을 추가하세요.

```xml
<?xml version="1.0" encoding="utf-8"?>
<resources xmlns:tools="http://schemas.android.com/tools"
    tools:keep="@drawable/btn_left_*,@drawable/btn_right_*" />
```

#### 4. 적용 확인 (선택)

출시 APK에 리소스가 남아 있는지 Android Studio APK Analyzer 또는 아래 명령으로 확인할 수 있습니다. 결과가 0이면 리소스가 제거된 상태입니다.

```
aapt2 dump resources app-release.apk | grep -c "drawable/btn_left_"
```

# 5. Changelog

## Version 2.7.11(2026.11.10)

**변경 사항**

* 메모리 사용 개선: 배너 갱신·Activity 재생성 후 사용이 끝난 광고 객체가 메모리에서 해제되지 않던 문제 수정
  * AdMob 미디에이션 Cauly 맞춤 이벤트 배너 정리
  * 초기화에 넘긴 Activity를 SDK가 계속 참조하던 문제(AdWhalePrivacy, 초기화 리스너, AdMob 미디에이션 어댑터 초기화)
  * Admize SDK가 광고를 만든 Activity를 계속 참조하던 문제(Admize SDK 1.0.10)
* AdMob 어댑터의 Google Mobile Ads SDK 24.3.0 → 25.4.0
  * AdMob 미디에이션 어댑터도 GMA 25.4.0 기준 버전으로 함께 올려야 합니다(버전 설정 가이드 2.7.11 참고)
  * AdMob 미디에이션 어댑터를 쓰는 Kotlin 앱은 Kotlin Gradle 플러그인 2.2.0 이상이 필요합니다

**포함된 네트워크 SDK**

* Cauly SDK 3.5.47
* Admize SDK 1.0.10
* AdFit SDK 3.21.17
* AdMob SDK 25.4.0
* Levelplay SDK 8.12.0

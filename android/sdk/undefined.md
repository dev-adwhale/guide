# 주요공지 및 안내사항

### 기본 안내사항

* **ADwhale Mediation SDK 최신 버전 사용을 권장합니다.** 하위 버전의 기술 지원은 별도로 문의해 주세요.
* ADwhale Mediation SDK는 Android API Level 24 이상에서 동작합니다.
* 광고 형식별 가이드에 안내된 `resume()` / `destroy()` 등 생명주기 API를 Activity·Fragment 생명주기에 맞춰 호출해 주세요. 호출하지 않으면 광고 노출과 수익에 불이익이 생길 수 있습니다.
* SDK를 업데이트할 때는 미디에이션·코어·어댑터 모듈을 모두 같은 배포 버전으로 함께 올려 주세요. 버전별 조합은 [Changelog](7.-changelog.md)와 [버전 설정 가이드](https://cdn.fsn.co.kr/guide/sdk/adwhale/adwhale-mediation-guide\(ko\).html)를 참고하세요.

### 공지사항 (필독)

#### 2026/11/03

**SDK 2.7.10 진단 로그 수집 기능 포함 (Google Play 데이터 보안 양식 반영 필요)**

AdWhale Android SDK 2.7.10부터 광고 로드 오류의 원인을 분석하기 위한 **진단 로그 수집 기능**이 포함됩니다.

* 기본값은 **수집하지 않음**입니다. 원인 분석이 필요한 경우에 한해 AdWhale이 관리 콘솔에서 해당 매체의 수집을 켜고, 분석이 끝나면 다시 끕니다.
* 수집을 켜고 끄는 데 매체 코드 변경이나 앱 업데이트는 필요 없습니다.
* 앱 업데이트 없이 켜질 수 있으므로, **SDK 2.7.10 이상을 적용한 앱 버전을 배포할 때 Google Play 데이터 보안 양식과 앱 개인정보 처리방침에 미리 반영**해 주세요.
* 광고 ID, 위치, 연락처 등 개인정보는 수집하지 않습니다.

수집 항목과 양식 작성 기준은 아래 [진단 로그 수집 안내](undefined.md#undefined-2)를 참고하세요.



**Android Gradle Plugin 9 리소스 축소(shrinkResources) 사용 시 keep 설정 안내**

AGP 9 이상에서 릴리스 빌드에 `shrinkResources true`를 사용하면, 일부 광고 네트워크 SDK가 이름으로 찾는 리소스가 빌드 과정에서 제거될 수 있습니다. \
앱 모듈의 `app/src/main/res/raw/keep.xml`에 해당 리소스를 유지하도록 설정해 주세요. 설정 방법은 [리소스 축소(shrinkResources) 설정](1./1.6-shrinkresources.md) 페이지를 참고하세요.

| 네트워크            | 증상                                      | 안내 위치                                                                                                                     |
| --------------- | --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| Pangle          | SDK 초기화 실패 (`resources not found`)      | [버전 설정 가이드](https://cdn.fsn.co.kr/guide/sdk/adwhale/adwhale-mediation-guide\(ko\).html)에서 Pangle 선택 시 표시되는 keep.xml 블록    |
| Mintegral       | 광고 노출 실패 (`3900 no mbridge_... layout`) | [버전 설정 가이드](https://cdn.fsn.co.kr/guide/sdk/adwhale/adwhale-mediation-guide\(ko\).html)에서 Mintegral 선택 시 표시되는 keep.xml 블록 |
| Cauly (앱 종료 광고) | 종료 팝업 버튼이 배경 없이 글자만 표시                  | [리소스 축소(shrinkResources) 설정](1./1.6-shrinkresources.md)                                                                   |

### 진단 로그 수집 안내

AdWhale Android SDK 2.7.10부터 광고 로드 오류의 원인을 분석하기 위한 진단 로그 수집 기능이 포함됩니다.

#### 1. 수집 방식

* 수집 여부는 AdWhale이 관리 콘솔에서 설정합니다. 기본값은 **수집하지 않음**이며, 광고 로드 오류의 원인 분석이 필요한 경우에 한해 해당 매체의 수집을 켭니다. 분석이 끝나면 다시 끕니다.
* 수집이 켜진 동안 SDK가 진단 정보를 수집해 AdWhale 서버로 전송합니다. 매체 코드 변경이나 앱 업데이트는 필요 없습니다.
* 매체나 앱 사용자가 수집을 켜거나 끄는 기능은 제공하지 않습니다.
* 광고를 로드·노출할 때만 기록합니다. 앱이 포그라운드 상태였는지는 기록 항목으로 함께 남깁니다.
* 전체가 아니라 AdWhale이 정한 비율만큼만 전송합니다(샘플링).

#### 2. 대상 광고 형식

보상형, 전면, 앱 오프닝, 앱 종료, 앱 내 화면 전환 (배너·네이티브 제외)

#### 3. 수집 항목

| 구분          | 항목                                                                                                     |
| ----------- | ------------------------------------------------------------------------------------------------------ |
| 광고 로드 결과    | 네트워크별 결과(성공·실패·시간 초과), 오류 코드·메시지, 소요 시간, 하위 광고 네트워크 이름과 응답 시간(AdMob 미디에이션)                             |
| 설정 조회 결과    | 소요 시간, 실패 원인(네트워크 오류, HTTP 상태)                                                                         |
| 광고 노출·보상 결과 | 노출 성공·실패, 보상 지급 여부, 보상·닫힘 시각, 이전 광고를 닫은 뒤 경과 시간                                                        |
| 실행 환경       | 회선 종류(Wi-Fi·모바일 등), Private DNS 설정 모드, VPN 사용 여부, 앱 포그라운드 여부, 기기 모델, OS 버전, 앱 버전, SDK 버전, 앱 프로세스 실행 시간 |
| 식별 정보       | 매체 ID, 지면 ID, 설치 단위 랜덤 ID(앱 재설치 시 변경, 광고 ID 아님)                                                        |

**수집하지 않는 항목**: 광고 ID, 위치, 연락처, 파일, 설치된 앱 목록 등 개인정보

#### 4. 전송과 보관

* 전송은 HTTPS로만 합니다.
* 기기: 전송에 실패한 기록은 앱 내부 저장소에 최대 200건·7일까지 보관했다가 다시 전송합니다. 앱을 삭제하면 함께 삭제됩니다.
* 서버: 7일 보관 후 삭제합니다.

#### 5. Google Play 데이터 보안 양식 작성 안내

SDK 2.7.10 이상을 적용한 앱 버전을 배포할 때, 아래 기준으로 Google Play Console의 데이터 보안 양식을 작성해 주세요. 아래 답은 AdWhale SDK 진단 로그 기준이며, 앱의 데이터 처리 방식에 따라 답이 달라질 수 있습니다.

**데이터 수집·공유 여부**

| 질문                                | 답변                    |
| --------------------------------- | --------------------- |
| 앱에서 필수 사용자 데이터 유형을 수집하거나 공유하나요?   | 예                     |
| 앱에서 수집하는 모든 사용자 데이터를 암호화하여 전송하나요? | 예                     |
| 사용자가 데이터 삭제를 요청할 수 있는 방편을 제공하나요?  | 아니요 (서버에서 7일 후 자동 삭제) |

**데이터 유형**

| 유형                                 | 답변                        |
| ---------------------------------- | ------------------------- |
| 앱 정보 및 성능 → 진단                     | O                         |
| 앱 정보 및 성능 → 비정상 종료 로그, 기타 앱 성능 데이터 | X                         |
| 기기 또는 기타 식별자                       | O (설치 단위 랜덤 ID, 광고 ID 아님) |
| 개인정보, 금융정보, 위치, 앱 활동 등 그 밖의 유형     | X                         |

**데이터 사용 및 처리 (진단, 기기 또는 기타 식별자 공통)**

| 질문                     | 답변                     |
| ---------------------- | ---------------------- |
| 수집됨 / 공유됨              | 수집됨 O, 공유됨 O           |
| 일시적으로 처리되나요?           | X (서버에 7일 보관)          |
| 필수인가요, 사용자가 선택할 수 있나요? | 필수 (사용자가 수집을 중지할 수 없음) |
| 수집·공유 목적               | 애널리틱스 O, 그 밖의 목적 X     |

앱 개인정보 처리방침에는 위 [수집 항목](undefined.md#id-3)과 [전송과 보관](undefined.md#id-4) 내용을 반영해 주세요. \
연동한 광고 네트워크 SDK의 수집 항목은 각 네트워크의 안내를 별도로 확인해 주세요.

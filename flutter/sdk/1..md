# 1. 시작하기 전에

본 문서는 ADwhale Mediation SDK를 파트너사의 Flutter 안드로이드 및 iOS 어플리케이션에 연동하기 위한 가이드 문서입니다. 연동 전에 다음의 안내 사항을 반드시 읽어 주시기 바랍니다.

{% hint style="info" %}
본 문서는 최신 ADwhale Mediation SDK 버전을 기준으로 업데이트 되고 있습니다.

하위 버전의 기술지원은 별도 문의 바랍니다.
{% endhint %}

{% tabs %}
{% tab title="Android" %}
### **Android 요구사항**

* 안드로이드 지원 버전
  * Android API Level 24 이상
* 안드로이드 타겟 버전 지원
  * API Level 35
  * GooglePlay의 타겟 API 수준 요구사항 충족하기
* Support Library
  * AndroidX 대응
  * Android Support Library
* Kotlin Gradle 플러그인
  * 2.0.0 이상
  * AdMob 어댑터를 함께 쓰는 경우 **2.2.0 이상** (Flutter SDK 2.7.11+0부터)



{% hint style="warning" %}
**2.7.11+0부터 AdMob 어댑터를 사용하면 Kotlin Gradle 플러그인 2.2.0 이상이 필요합니다.**

AdMob 어댑터 25.4.0.0이 사용하는 Google Mobile Ads SDK(GMA) 25.4.0은 Kotlin 2.3 메타데이터로 빌드되어 있습니다. Flutter 기본 템플릿의 `MainActivity.kt`처럼 앱 모듈에 Kotlin 코드가 있으면, Kotlin 2.1.x 이하에서는 `compileReleaseKotlin`이 `Module was compiled with an incompatible version of Kotlin` 오류로 실패합니다. 설정 방법은 [3.1 프로젝트 빌드 설정](https://adwhale.gitbook.io/adwhale-mediation-sdk/flutter/sdk/3./3.1) 페이지를 참고하세요.
{% endhint %}

{% hint style="danger" %}
**Google Play 정책 안내**

**2026년 8월 31일부터** Google Play에 제출되는 모든 앱은 **Android 16 (API Level 36) 이상**을 `targetSdkVersion`으로 지정해야 합니다.

* 참고: [https://developer.android.com/google/play/requirements/target-sdk?hl=ko](https://developer.android.com/google/play/requirements/target-sdk?hl=ko)

***

**2025년 11월 11일부터** Android 15 이상을 타겟팅하는 모든 앱은 **64비트 기기에서 16KB페이지 크기를 지원**해야 합니다.

* 참고: [https://developer.android.com/guide/practices/page-sizes?hl=ko](https://developer.android.com/guide/practices/page-sizes?hl=ko)
{% endhint %}

{% tab title="iOS" %}
### **iOS 요구사항**

{% hint style="danger" %}
**Flutter** 프로젝트는 **Cocoapod 기반 Swift**가 기본 네이티브 언어로 사용됩니다.

사용하는 프로젝트 구조에 맞게 가이드를 적용해 주세요.
{% endhint %}

* 최소 지원 사양
  * iOS 13.0 이상
  * Xcode 26.0 이상
  * CocoaPods

{% hint style="info" %}
앱 스토어 커넥트에 업로드 날짜에 따른 빌드에 사용하는 Xcode 버전 요구사항은 다음과 같습니다.

* 2025년 4월 24일부터: **Xcode 16.0 이상 버전 사용이 필요합니다.**\
  [**https://developer.apple.com/news/upcoming-requirements/?id=02212025a**](https://developer.apple.com/news/upcoming-requirements/?id=02212025a)
* 2026년 4월 28일부터: **Xcode 26.0 이상 버전 사용이 필요합니다.**\
  [**https://developer.apple.com/kr/news/?id=ueeok6yw**](https://developer.apple.com/kr/news/?id=ueeok6yw)
{% endhint %}

{% hint style="danger" %}
**Xcode15** 이상에서 빌드할 경우, **iOS Deployment Target Version(최소 지원 버전)을 13.0 이상으로 설정**합니다.

iOS 13.0 이상으로 설정하지 않을 경우, 특정 광고 네트워크의 초기화 과정에서 비정상 종료(Crash)가 발생할 수 있습니다.
{% endhint %}



{% hint style="warning" %}
**Xcode 27 이상에서는 iOS Deployment Target을 15.0 이상으로 설정해 주세요.**

Xcode 27에서는 Deployment Target이 15.0 미만이면 `IPHONEOS_DEPLOYMENT_TARGET is set to 13.0, but the range of supported deployment target versions is 15.0 to …` 오류로 빌드가 실패합니다. 앱 타깃과 Pod 타깃을 함께 15.0 이상으로 맞춰 주세요.

1. Xcode에서 Runner 타깃의 **Minimum Deployments**를 15.0 이상으로 설정합니다.
2. `ios/Podfile`의 `platform`을 15.0으로 바꾸고, 기존 `post_install` 반복문 안에 `IPHONEOS_DEPLOYMENT_TARGET` 설정을 추가한 뒤 `pod install`을 다시 실행합니다. `post_install`은 한 번만 쓸 수 있으므로 새로 만들지 말고 기존 블록에 넣어 주세요.
{% endhint %}

```ruby
# ios/Podfile
platform :ios, '15.0'  # 추가

...

post_install do |installer|
  installer.pods_project.targets.each do |target|
    flutter_additional_ios_build_settings(target)
    target.build_configurations.each do |config|                    # 추가
      config.build_settings['IPHONEOS_DEPLOYMENT_TARGET'] = '15.0'  # 추가
    end                                                             # 추가
  end
end
```

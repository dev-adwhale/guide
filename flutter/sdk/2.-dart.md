### 최신 SDK version : 2.7.11+0

### Version Usage Guide

**정확한 버전으로 고정해서 사용해 주세요.**

Flutter SDK에는 Android 미디에이션 SDK 버전이 함께 들어 있습니다. 버전이 바뀌면 어댑터 버전, Kotlin 조건 같은 앱 설정도 함께 바뀔 수 있습니다.

```
dependencies:
  adwhale_sdk_flutter: 2.7.11+0
```

* 앱이 정한 버전만 설치됩니다.
* 업데이트할 때는 버전을 직접 바꾸고, [3.1 프로젝트 빌드 설정](https://adwhale.gitbook.io/adwhale-mediation-sdk/flutter/sdk/3./3.1)의 어댑터 버전과 [1. 시작하기 전에](https://adwhale.gitbook.io/adwhale-mediation-sdk/flutter/sdk/1.)의 Kotlin 조건을 함께 확인해 주세요.

{% hint style="warning" %}
`^2.7.11+0`처럼 범위로 지정하면 `flutter pub upgrade`를 실행하거나 `pubspec.lock`이 없는 환경에서 빌드할 때 Android SDK가 다른 버전으로 함께 바뀔 수 있습니다. `~` 표기는 Dart에서 지원하지 않아 `flutter pub get`이 실패합니다.
{% endhint %}

#### pubspec.lock 파일을 커밋해 주세요

`pubspec.lock`을 저장소에 커밋하면, 빌드 환경마다 같은 버전이 설치됩니다.

# 3.1 로거 설정

{% hint style="info" %}
AdWhaleLog 를 통해 SDK 로그레벨 및 로그 내용을 컨트롤 할 수 있습니다.
{% endhint %}

{% tabs %}
{% tab title="Swift" %}
**AdWhaleLog 클래스 API 설명**

```swift
AdWhaleLog.setLogLevel(.debug)
```
{% endtab %}

{% tab title="Objective-C" %}
**AdWhaleLog 클래스 API 설명**

```objective-c
[AdWhaleLog setLogLevel:AdWhaleLogLevelDebug];
```
{% endtab %}
{% endtabs %}

| 레벨       | 값      |
| -------- | ------ |
| .none    | 0      |
| .error   | 1      |
| .warn    | 2(기본값) |
| .info    | 3      |
| .debug   | 4      |
| .verbose | 5      |

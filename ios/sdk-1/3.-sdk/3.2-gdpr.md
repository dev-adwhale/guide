# 3.2 GDPR 사전 동의 설정

### GDPR 개요

* **GDPR(General Data Protection Regulation)**&#xC740; European Union(EU)의 개인정보 보호 법령입니다.
* 유럽 경제 지역(EEA) 사용자에 대해서는 개인정보 및 광고 식별자 수집·활용에 대해 **사전 동의**를 받아야 합니다.

### 적용 대상

{% hint style="info" %}
* 앱 사용자가 **유럽 경제 지역(EEA)**&#xC5D0; 속하는 경우
* EEA 외 지역 사용자에게는 동의 팝업이 표시되지 않음
{% endhint %}

### 동의 수집 방식

{% hint style="info" %}
* EEA 사용자 동의는 Google AdMob의 User Messaging Platform(UMP SDK)를 통해 처리됩니다.
* UMP SDK 를 사용하지 않는 광고 네트워크를 운영하는 경우 별도의 인터페이스(setGdpr)를 제공합니다.
  * 예: Cauly, Levelplay 등
{% endhint %}

### 필수 설정 사항(중요)

{% hint style="warning" %}
**1) 스토어 정책 설정과 SDK 설정 일치**

* 플랫폼 콘솔에 설정한 데이터 수집 항목과 SDK에서 실제 동작하는 개인정보/광고 설정이 반드시 일치해야 합니다.
  * Android → Google Play Console의 데이터 보안 및 광고설정
  * iOS → App Store Connect
* 설정 불일치 시:
  * 정책 위반 가능
  * 광고 제한(Limited Ads) 발생 가능

**2) Initialize를 진행 후 호출해야 합니다.**
{% endhint %}

### **샘플코드**

{% tabs %}
{% tab title="Swift" %}
```swift
AdWhaleMediationAds.requestGdprConsent(from: self) { isSuccess, message in
    if isSuccess {
        print("GDPR 동의 처리 완료")
    }
    // 동의 처리 후 SDK 초기화 / 광고 로드
}
```

Delegate 방식으로 구현하는 경우

```swift
AdWhaleMediationAds.requestGdprConsent(from: self, delegate: self)

// AdWhaleMediationGdprConsentDelegate
func onGdprConsentComplete(isSuccess: Bool, message: String) { }
```

```

```

### 상태 조회 및 초기화

{% tabs %}
{% tab title="Swift" %}
```swift
let status = AdWhaleMediationAds.gdprConsentStatus  // .obtained / .required / .notRequired / .unknown
let hasConsent = AdWhaleMediationAds.gdprConsent    // Bool

AdWhaleMediationAds.resetGdprConsentStatus()        // UMP 리셋 + 저장된 동의 제거
```
{% endtab %}

{% tab title="Objective-C" %}
```objective-c
AdWhaleGdprConsentStatus status = [AdWhaleMediationAds gdprConsentStatus];
BOOL hasConsent = [AdWhaleMediationAds gdprConsent];

[AdWhaleMediationAds resetGdprConsentStatus];
```
{% endtab %}
{% endtabs %}

| 상태           | 값 | 의미             |
| ------------ | - | -------------- |
| .unknown     | 0 | 아직 확인되지 않음     |
| .required    | 1 | 동의가 필요한 지역     |
| .notRequired | 2 | 동의가 필요하지 않은 지역 |
| .obtained    | 3 | 동의를 받음         |

### 수동 동의 설정(non-UMP 네트워크)

UMP SDK 를 사용하지 않는 광고 네트워크를 운영하는 경우 별도의 인터페이스(setGdpr)를 제공합니다.

{% tabs %}
{% tab title="Swift" %}
```swift
AdWhaleMediationAds.setGdpr(true)
```
{% endtab %}

{% tab title="Objective-C" %}
```objective-c
[AdWhaleMediationAds setGdpr:YES];
```
{% endtab %}
{% endtabs %}

{% hint style="info" %}
`setGdpr` 로 설정한 값은 `UserDefaults` 에 저장되어 앱을 재시작해도 유지됩니다. 설정을 리셋하려면,  `resetGdprConsentStatus()` 를 호출하세요. \
UMP 동의 상태(`gdprConsentStatus`)는 SDK 가 저장하지 않고 UMP 가 관리합니다.
{% endhint %}

### 주의사항

{% hint style="danger" %}
애드몹의 경우, 애드몹 메시지에 **IDFA(ATT) 플로우를 함께 구성**한 경우, UMP 동의 폼이 ATT 권한 요청까지 수행합니다.\
이때 앱이 실행 직후 `requestTrackingAuthorization` 을 먼저 호출하면 그 설치본의 ATT 요청 기회가\
소진되어 **동의 폼이 닫히지 않는 현상**이 발생합니다. ATT 요청은 UMP 플로우에 맡기세요.
{% endhint %}

{% hint style="warning" %}
UMP 는 동의 결과를 IAB 표준 키(`IABTCF_PurposeConsents`, `IABTCF_VendorConsents` 등)로\
`UserDefaults.standard` 에 기록합니다. **앱에서 이 키를 직접 수정하지 마세요.**
{% endhint %}

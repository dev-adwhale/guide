# 주요공지 및 안내사항

### 기본 안내사항

* **ADwhale Mediation iOS SDK 최신 버전 사용을 권장합니다.** 하위 버전의 기술 지원은 별도로 문의해 주세요.
* ADwhale Mediation iOS SDK는 iOS 15.0 이상에서 동작합니다.
* 광고 형식별 가이드에 안내된 `destroy()` 등 생명주기 API를 화면(UIViewController) 생명주기에 맞춰 호출해 주세요. 다 쓴 광고 객체를 정리하지 않으면 메모리가 해제되지 않을 수 있습니다.
* SDK를 업데이트할 때는 코어(`AdWhaleSDK`)와 어댑터를 같은 패키지 버전으로 함께 올려 주세요. 버전별 변경 사항은 [Changelog](changelog.md)를 참고하세요.

***

### 공지사항 (필독)

#### 2026/11/17

**신규 iOS SDK 1.1.0 출시 및 기존 SDK 전환 안내**

신규 SDK(ADwhale Mediation iOS SDK)는 기존 애드웨일 iOS SDK 1.0.x와 모듈 이름은 같지만 **다른 제품**입니다.

* 기존 1.0.x는 계속 동작하므로 서둘러 전환하지 않아도 됩니다. 기존 SDK 가이드는 [SDK 연동 가이드](../sdk-legacy/)에서 계속 제공합니다.
* 전환하려면 앱 코드를 고쳐야 합니다. 광고단위 ID 대신 애드웨일 지면 ID(`placementUid`)를 쓰고, 클래스도 모두 바뀌었습니다. 두 SDK는 함께 넣을 수 없습니다. 자세한 내용은 [들어가기 전에](migration.md)를 참고하세요.
* 신규 광고 형식(팝업)과 신규 네트워크(LevelPlay · Cauly · AdFit · Admize · AdManager)는 신규 SDK에서만 제공합니다.
* Flutter · React Native 플러그인을 쓰는 앱은 아직 전환하지 마세요. 플러그인이 기존 SDK를 사용합니다.

**진단 로그 수집 기능 포함**

AdWhale iOS SDK 1.1.0부터 광고 로드 오류의 원인을 분석하기 위한 **진단 로그 수집 기능**이 포함됩니다.

* 기본값은 **수집하지 않음**입니다. 원인 분석이 필요한 경우에 한해 AdWhale이 관리 콘솔에서 해당 매체의 수집을 켜고, 분석이 끝나면 다시 끕니다.
* 수집을 켜고 끄는 데 매체 코드 변경이나 앱 업데이트는 필요 없습니다.
* 원인 분석을 위해 수집이 필요해지면 AdWhale이 먼저 연락드리며, App Store 개인정보 라벨과 앱 개인정보 처리방침에 반영된 것을 확인한 뒤에 수집을 켭니다.
* 광고 식별자(IDFA), 위치, 연락처 등 개인정보는 수집하지 않습니다.

수집 항목과 라벨 작성 기준은 아래 [진단 로그 수집 안내](notice.md#undefined-2)를 참고하세요.

***

### 진단 로그 수집 안내

AdWhale iOS SDK 1.1.0부터 광고 로드 오류의 원인을 분석하기 위한 진단 로그 수집 기능이 포함됩니다.

#### 1. 수집 방식

* 수집 여부는 AdWhale이 관리 콘솔에서 설정합니다. 기본값은 **수집하지 않음**이며, 광고 로드 오류의 원인 분석이 필요한 경우에 한해 해당 매체의 수집을 켭니다. 분석이 끝나면 다시 끕니다. 수집을 켜기 전에 해당 매체에 먼저 연락드립니다.
* 수집이 켜진 동안 SDK가 진단 정보를 수집해 AdWhale 서버로 전송합니다. 매체 코드 변경이나 앱 업데이트는 필요 없습니다.
* 매체나 앱 사용자가 수집을 켜거나 끄는 기능은 제공하지 않습니다.
* 광고를 로드·노출할 때만 기록합니다. 앱이 포그라운드 상태였는지는 기록 항목으로 함께 남깁니다.
* 전체가 아니라 AdWhale이 정한 비율만큼만 전송합니다(샘플링).

#### 2. 대상 광고 형식

보상형, 전면, 앱 오프닝, 팝업(앱 내 화면 전환) (배너·네이티브 제외)

#### 3. 수집 항목

| 구분          | 항목                                                                         |
| ----------- | -------------------------------------------------------------------------- |
| 광고 로드 결과    | 네트워크별 결과(성공·실패·시간 초과), 오류 코드·메시지, 소요 시간, 하위 광고 네트워크 이름과 응답 시간(AdMob 미디에이션) |
| 설정 조회 결과    | 소요 시간, 실패 원인(네트워크 오류, HTTP 상태)                                             |
| 광고 노출·보상 결과 | 노출 성공·실패, 보상 지급 여부, 보상·닫힘 시각, 이전 광고를 닫은 뒤 경과 시간                            |
| 실행 환경       | 회선 종류(Wi-Fi·모바일 등), 앱 포그라운드 여부, 기기 모델, OS 버전, 앱 버전, SDK 버전, 앱 프로세스 실행 시간   |
| 식별 정보       | 매체 ID, 지면 ID, 설치 단위 랜덤 ID(앱 재설치 시 변경, 광고 식별자(IDFA) 아님)                     |

**수집하지 않는 항목**: 광고 식별자(IDFA), 위치, 연락처, 파일, 사진 등 개인정보

{% hint style="info" %}
Android 에서 수집하는 Private DNS 설정 모드와 VPN 사용 여부는 iOS 에서 수집하지 않습니다. iOS 에는 이 값을 확인하는 공개 API 가 없습니다.
{% endhint %}

#### 4. 전송과 보관

* 전송은 HTTPS로만 합니다.
* 기기: 전송에 실패한 기록은 앱 내부 저장소에 최대 200건·7일까지 보관했다가 다시 전송합니다. 앱을 삭제하면 함께 삭제됩니다.
* 서버: 7일 보관 후 삭제합니다.

#### 5. App Store 개인정보 라벨 작성 안내

진단 로그 수집이 필요해 AdWhale이 연락드리면, 아래 기준으로 App Store Connect 의 앱 개인정보 보호(App Privacy) 항목을 작성해 주세요. 아래 답은 AdWhale SDK 진단 로그 기준이며, 앱의 데이터 처리 방식에 따라 답이 달라질 수 있습니다.

{% hint style="info" %}
AdWhale SDK 에 포함된 개인정보 매니페스트(`PrivacyInfo.xcprivacy`)에는 진단 로그 항목(성능 데이터, 기타 진단 데이터, 기기 ID 의 앱 기능 목적)이 미리 선언되어 있습니다. 그래서 Xcode 에서 생성하는 개인정보 보고서(Privacy Report)에는 수집 여부와 관계없이 아래 항목이 표시됩니다.
{% endhint %}

**데이터 유형**

| 유형                                    | 답변                               |
| ------------------------------------- | -------------------------------- |
| 진단 → 성능 데이터(Performance Data)         | O                                |
| 진단 → 기타 진단 데이터(Other Diagnostic Data) | O                                |
| 진단 → 충돌 데이터(Crash Data)               | X                                |
| 식별자 → 기기 ID(Device ID)                | O (설치 단위 랜덤 ID, 광고 식별자(IDFA) 아님) |
| 연락처 정보, 위치, 사용자 콘텐츠, 금융 정보 등 그 밖의 유형  | X                                |

**데이터 사용 목적과 연결 여부 (성능 데이터, 기타 진단 데이터, 기기 ID 공통)**

| 질문                   | 답변                      |
| -------------------- | ----------------------- |
| 수집 목적                | 앱 기능(App Functionality) |
| 사용자의 신원에 연결되나요?      | 아니요                     |
| 추적(Tracking)에 사용되나요? | 아니요                     |

{% hint style="info" %}
기기 ID 는 연동한 광고 네트워크가 광고 식별자(IDFA)를 수집하기 때문에 이미 "제3자 광고" 목적 · 추적 사용으로 표시되어 있을 수 있습니다. 진단 로그를 위해서는 같은 기기 ID 항목에 "앱 기능" 목적만 추가해 주세요.
{% endhint %}

앱 개인정보 처리방침에는 위 수집 항목과 전송과 보관 내용을 반영해 주세요.\
연동한 광고 네트워크 SDK의 수집 항목은 각 네트워크의 안내를 별도로 확인해 주세요.

# 2. Npm 패키지 추가하기

{% hint style="info" %}
프로젝트 폴더 최상단 위치에서 아래 명령을 실행해주세요.&#x20;

```
yarn add adwhale-sdk-react-native@2.7.1100 --exact
  또는
npm install adwhale-sdk-react-native@2.7.1100 --save-exact
```



아래 링크에서도 추가 방법을 확인할 수 있습니다.

[https://www.npmjs.com/package/adwhale-sdk-react-native](https://www.npmjs.com/package/adwhale-sdk-react-native)
{% endhint %}

명령어를 실행하고 나면 package.json에서 다음과 같이 패키지가 추가된 것을 확인할 수 있습니다.

```json
  "dependencies": {
    "adwhale-sdk-react-native": "2.7.1100"
  },
```

### Version Usage Guide

**정확한 버전으로 고정하는 방식을 권장합니다.**

React Native SDK에는 Android 미디에이션 SDK 버전이 함께 들어 있습니다. 버전이 바뀌면 어댑터 버전, Kotlin 조건 같은 앱 설정도 함께 바뀔 수 있습니다.

#### 정확한 버전으로 고정 (권장)

```json
{
  "adwhale-sdk-react-native": "2.7.1100"
}
```

* 앱이 정한 버전만 설치됩니다.
* 업데이트할 때 이 가이드의 어댑터 버전과 Kotlin 조건을 함께 확인해 주세요.
* 설치 명령: `yarn add adwhale-sdk-react-native@2.7.1100 --exact` 또는 `npm install adwhale-sdk-react-native@2.7.1100 --save-exact`

#### 범위로 지정 (`~`)

```json
{
  "adwhale-sdk-react-native": "~2.7.1100"
}
```

* `>=2.7.1100 <2.8.0` 범위입니다.
* **RN 핫픽스뿐 아니라 2.7 계열 Android SDK 업데이트도 자동으로 설치됩니다.** 이때 어댑터 버전과 Kotlin 조건이 바뀔 수 있습니다.
* 자동 반영을 원할 때만 사용해 주세요.

#### lock 파일을 커밋해 주세요

`yarn.lock` 또는 `package-lock.json`을 저장소에 커밋하면, 빌드 환경마다 같은 버전이 설치됩니다.

#### Troubleshooting

Android 빌드 오류 발생 시:

```
cd android
./gradlew clean
```

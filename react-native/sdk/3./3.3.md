# 3.3 파트너 네트워크 연동 (선택사항)

{% hint style="info" %}
광고 수익 극대화를 위해 파트너 네트워크별 최적화 설정이 필요합니다.\
연동을 희망하시는 네트워크 목록을 사전에 전달해 주시면, 보다 정밀한 수익 최적화 세팅으로 맞춤형 세팅을 지원해 드립니다.
{% endhint %}

### **미디에이션 SDK 환경 설정 빌더 접속 링크**

이 빌더는 귀사가 선택한 네트워크에 맞춰 **필요한 모든 설정 코드를 자동으로 생성**합니다.&#x20;

생성된 코드를 해당 단계의 가이드에 따라 순서대로 복사 및 붙여넣기 하시면, **모든 프로젝트 초기 설정이 완료**됩니다.

* **애드몹 파트너 네트워크 연동 사용자를 위한 빌더 사용방법:**&#x20;
  * 링크 접속 > \[운영대행] 체크 > \[Admob] 선택 > 네트워크 선택&#x20;
  * 각 항목 복사 후 > 프로젝트 내 해당 항목들에 붙여넣기
* **레벨플레이 파트너 네트워크 연동 사용자를 위한 빌더 사용방법:**&#x20;
  * 링크 접속 > \[운영대행] 체크 > \[Unity(Levelplay)] 선택 > 네트워크 선택
  * 각 항목 복사 후 > 프로젝트 내 해당 항목들에 붙여넣기

**접속링크 (2.7.11):** [https://cdn.fsn.co.kr/guide/sdk/adwhale/2.7.11/adwhale-mediation-guide(ko).html](https://cdn.fsn.co.kr/guide/sdk/adwhale/2.7.11/adwhale-mediation-guide\(ko\).html)

{% hint style="info" %}
React Native SDK 2.7.1100에는 Android SDK 2.7.11이 들어 있습니다. 2.7.11 빌더를 사용해 주세요.
{% endhint %}

### **iOS 애드몹 파트너 네트워크 연동 사용자를 위한 사용방법**

{% hint style="info" %}
애드몹 파트너 네트워크(Pangle, Vungle, AppLovin ...)를 연동하고 싶으실 경우, 필요한 네트워크만 앱의 **Podfile**에 추가해 주세요.

1. 프로젝트의 `ios/Podfile`을 엽니다.
2. 앱 타겟(`target '{앱 타겟 이름}' do`) 안, `use_react_native!(...)` 아래에 어댑터 pod를 추가합니다.
{% endhint %}

```ruby
# ios/Podfile
target 'YourApp' do
  config = use_native_modules!

  use_react_native!(
    :path => config[:reactNativePath],
    :app_path => "#{Pod::Config.instance.installation_root}/.."
  )

  # AdMob Mediation: 필요한 네트워크만 추가해 주세요 (Google-Mobile-Ads-SDK ~> 13.x 호환)
  pod 'GoogleMobileAdsMediationUnity', '~> 4.16.6.1'
  pod 'GoogleMobileAdsMediationMoloco', '~> 4.4.1.0'
  pod 'GoogleMobileAdsMediationAppLovin', '~> 13.5.1.0'
  pod 'GoogleMobileAdsMediationInMobi', '~> 11.1.1.1'
  pod 'GoogleMobileAdsMediationVungle', '~> 7.7.0.0'
  pod 'GoogleMobileAdsMediationFyber', '~> 8.4.4.1'
  pod 'GoogleMobileAdsMediationMintegral', '~> 8.0.7.0'
  pod 'GoogleMobileAdsMediationPangle', '~> 7.9.0.6.0'
  pod 'GoogleMobileAdsMediationIronSource', '~> 9.3.0.0.1'

  post_install do |installer|
    react_native_post_install(
      installer,
      config[:reactNativePath],
      :mac_catalyst_enabled => false
    )
    # 아래 3번의 -ObjC 설정을 여기에 이어서 넣습니다.
  end
end
```

{% hint style="info" %}
3\. **InMobi 등 일부 어댑터**는 앱 타겟의 **Other Linker Flags에 -ObjC**가 필요합니다. Xcode의 앱 타겟 > Build Settings > Other Linker Flags에 `-ObjC`를 추가하거나, `pod install` 때 자동으로 넣으려면 `post_install` 안에 다음을 추가해 주세요. `YourApp`은 앱 타겟 이름으로 바꿔 주세요.
{% endhint %}

```ruby
  # post_install do |installer| 블록 안, react_native_post_install(...) 아래
  app_project_path = File.join(__dir__, 'YourApp.xcodeproj')
  if File.exist?(app_project_path)
    require 'xcodeproj'
    project = Xcodeproj::Project.open(app_project_path)
    project.native_targets.each do |t|
      next unless t.name == 'YourApp'
      t.build_configurations.each do |cfg|
        flags = cfg.build_settings['OTHER_LDFLAGS'] || ['$(inherited)']
        flags = [flags] if flags.is_a?(String)
        cfg.build_settings['OTHER_LDFLAGS'] = (flags + ['-ObjC']).uniq
      end
      break
    end
    project.save
  end
```

{% hint style="info" %}
4\. 저장 후 터미널에서 실행합니다.

```
cd ios
rm -rf Pods Podfile.lock
pod install --repo-update
```

5\. 빌드와 실행은 `ios/{앱 이름}.xcworkspace`를 열어서 합니다. (Xcode에서 Product > Clean Build Folder > Run)

Expo 프로젝트는 `npx expo prebuild`로 `ios` 폴더를 만든 뒤 같은 방법으로 Podfile을 수정해 주세요. prebuild를 다시 실행하면 Podfile이 새로 만들어지므로, 계속 유지하려면 config plugin으로 넣는 것을 권장합니다.
{% endhint %}

{% hint style="danger" %}
#### Android / iOS AdMob 버전 충돌 여부

**Android**

* AdMob(Play Services Ads) 버전은 **ADwhale Mediation SDK**의 AdMob 어댑터가 사용하는 버전으로 결정됩니다.
* 이 React Native SDK는 Android 쪽에 AdMob 의존성을 직접 추가하지 않으며, AdMob 어댑터(`admob-sdk`)에 포함된 버전을 사용합니다.
* **ADwhale Mediation SDK 가 사용하는 애드몹 버전: 25.4.0 (AdMob 어댑터 25.4.0.0)**



**iOS**

* 이 React Native SDK는 iOS에서 **ADwhale Mediation SDK**를 CocoaPods로 가져옵니다.
* **ADwhale Mediation SDK 가 사용하는 애드몹 버전: 13.0.0**



**버전 충돌**

* Android와 iOS는 **서로 다른 빌드 체인**을 쓰므로, “Android AdMob 버전”과 “iOS Google-Mobile-Ads-SDK 버전”이 달라도 SDK 자체에서는 **충돌이 나지 않습니다**.
* iOS에서 앱이나 다른 라이브러리(예: `react-native-google-mobile-ads`)도 같은 **Google-Mobile-Ads-SDK**를 쓰면, CocoaPods가 **한 가지 버전으로 통일**해서 링크합니다.
* 앱에서 특정 버전을 사용하고 있거나 고정하고 싶다면, 앱의 `ios/Podfile`에서 `Google-Mobile-Ads-SDK` 버전을 지정하면 되나, 지정 버전과 다른 버전 사용시 예기치 못한 동작 및 에러가 발생할 수 있으니 유의 부탁드립니다.
{% endhint %}

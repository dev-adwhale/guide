# 3.5 Expo 설정

{% hint style="info" %}
Expo 프로젝트(Development Build, `npx expo prebuild` 사용)에서 3.1\~3.3의 설정을 넣는 방법입니다. Expo Go에서는 동작하지 않습니다. **Expo SDK 53, 54, 58**에서 확인했습니다.
{% endhint %}

{% hint style="warning" %}
Expo 프로젝트의 `android/`·`ios/` 폴더는 `npx expo prebuild`가 만드는 생성물입니다. 이 폴더의 파일(build.gradle, AndroidManifest.xml, Podfile, Info.plist)을 직접 고치면 `npx expo prebuild --clean`을 실행할 때 지워집니다. 아래처럼 **`app.json`과 config plugin에 설정을 넣어 주세요.**
{% endhint %}

| 3.1\~3.3 설정                                | Expo에서 넣는 곳                                                      |
| ------------------------------------------ | ---------------------------------------------------------------- |
| Android Maven 저장소                          | `app.json` > `expo-build-properties` > `android.extraMavenRepos` |
| Android 어댑터 의존성                            | config plugin `androidDependencies`                              |
| Kotlin Gradle 플러그인 2.2.0                   | Expo SDK별로 다름 (아래 「Expo SDK 버전별 차이」)                             |
| Android 난독화 규칙                             | 규칙 파일 + config plugin `proguardRulesFile`                        |
| Android 연동 키(PUBLISHER\_UID, AdMob APP ID) | config plugin `androidPublisherUid`, `androidAdmobAppId`         |
| iOS 연동 키(GADApplicationIdentifier)         | config plugin `iosAdmobAppId`                                    |
| iOS Podfile 저장소(source)                    | config plugin (자동)                                               |
| iOS 파트너 네트워크 pod                           | `app.json` > `expo-build-properties` > `ios.extraPods`           |
| iOS `-ObjC`                                | config plugin (자동)                                               |
| iOS Info.plist(ATT 문구, SKAdNetwork, ATS)   | `app.json` > `ios.infoPlist`                                     |

#### 1. 패키지 설치

```bash
npm install adwhale-sdk-react-native
npx expo install expo-build-properties
```

#### 2. config plugin 추가

프로젝트에 `plugins/withAdwhale.js` 파일을 추가합니다. 수정하지 않고 그대로 사용합니다.

```javascript
// plugins/withAdwhale.js
// ADwhale Mediation SDK 설정을 prebuild 때 android/·ios/에 넣는 config plugin
const fs = require('fs');
const path = require('path');
const {
  withAppBuildGradle,
  withAndroidManifest,
  withDangerousMod,
  withXcodeProject,
  withInfoPlist,
  AndroidConfig,
} = require('expo/config-plugins');

const MARKER = '// ADwhale (withAdwhale)';

// [Android] 앱 build.gradle dependencies에 추가: 3.1 dependencies 설정 + 3.3 빌더 결과
const withAdwhaleDependencies = (config, dependencies) =>
  withAppBuildGradle(config, (cfg) => {
    if (!cfg.modResults.contents.includes(MARKER)) {
      const lines = dependencies.map((d) => `    implementation '${d}'`).join('\n');
      cfg.modResults.contents = cfg.modResults.contents.replace(
        /dependencies\s*\{/,
        (m) => `${m}\n    ${MARKER}\n${lines}\n`
      );
    }
    return cfg;
  });

// [Android] AndroidManifest <application> meta-data: 3.2 SDK 연동 키 설정
const withAdwhaleManifest = (config, { androidPublisherUid, androidAdmobAppId }) =>
  withAndroidManifest(config, (cfg) => {
    const app = AndroidConfig.Manifest.getMainApplicationOrThrow(cfg.modResults);
    AndroidConfig.Manifest.addMetaDataItemToMainApplication(
      app, 'net.adwhale.sdk.mediation.PUBLISHER_UID', androidPublisherUid);
    AndroidConfig.Manifest.addMetaDataItemToMainApplication(
      app, 'com.google.android.gms.ads.APPLICATION_ID', androidAdmobAppId);
    return cfg;
  });

// [Android] 난독화 규칙 파일을 android/app/proguard-rules.pro 끝에 붙임: 3.1 난독화 설정
const withAdwhaleProguard = (config, proguardRulesFile) =>
  withDangerousMod(config, ['android', async (cfg) => {
    const src = path.join(cfg.modRequest.projectRoot, proguardRulesFile);
    const dst = path.join(cfg.modRequest.platformProjectRoot, 'app', 'proguard-rules.pro');
    const current = fs.existsSync(dst) ? fs.readFileSync(dst, 'utf8') : '';
    if (!current.includes('# ADwhale (withAdwhale)')) {
      fs.writeFileSync(dst, `${current}\n# ADwhale (withAdwhale)\n${fs.readFileSync(src, 'utf8')}\n`);
    }
    return cfg;
  }]);

// [iOS] Podfile 맨 위에 pod 저장소 추가: 3.1 iOS cocoapods
const withAdwhalePodSources = (config) =>
  withDangerousMod(config, ['ios', async (cfg) => {
    const podfile = path.join(cfg.modRequest.platformProjectRoot, 'Podfile');
    const contents = fs.readFileSync(podfile, 'utf8');
    if (!contents.includes('AdWhaleSDK_iOS.git')) {
      fs.writeFileSync(podfile,
        "source 'https://github.com/CocoaPods/Specs.git'\n" +
        "source 'https://github.com/dev-adwhale/AdWhaleSDK_iOS.git'\n\n" + contents);
    }
    return cfg;
  }]);

// [iOS] 앱 타겟 Other Linker Flags에 -ObjC 추가: 3.3 iOS
const withAdwhaleObjC = (config) =>
  withXcodeProject(config, (cfg) => {
    const configs = cfg.modResults.pbxXCBuildConfigurationSection();
    for (const key of Object.keys(configs)) {
      const bs = configs[key] && configs[key].buildSettings;
      if (!bs || !bs.INFOPLIST_FILE) continue; // 앱 타겟만
      let flags = bs.OTHER_LDFLAGS || ['"$(inherited)"'];
      if (!Array.isArray(flags)) flags = [flags];
      if (!flags.some((f) => String(f).includes('-ObjC'))) flags.push('"-ObjC"');
      bs.OTHER_LDFLAGS = flags;
    }
    return cfg;
  });

// [iOS] Info.plist GADApplicationIdentifier: 3.2 SDK 연동 키 설정
// (Expo SDK 54 이하는 app.json ios.infoPlist에 넣은 이 키를 prebuild가 지우므로 plugin으로 넣는다)
const withAdwhaleInfoPlist = (config, iosAdmobAppId) =>
  withInfoPlist(config, (cfg) => {
    cfg.modResults.GADApplicationIdentifier = iosAdmobAppId;
    return cfg;
  });

module.exports = function withAdwhale(config, props = {}) {
  config = withAdwhaleDependencies(config, props.androidDependencies || []);
  config = withAdwhaleManifest(config, props);
  if (props.proguardRulesFile) config = withAdwhaleProguard(config, props.proguardRulesFile);
  config = withAdwhaleInfoPlist(config, props.iosAdmobAppId);
  config = withAdwhalePodSources(config);
  config = withAdwhaleObjC(config);
  return config;
};
```

#### 3. 난독화 규칙 파일 추가 (Android)

[3.1 프로젝트 빌드 설정](3.1.md) Android 탭의 「(필수)proguard-rules.pro 난독화 설정」 규칙 전체를 프로젝트 루트의 `adwhale-proguard-rules.pro` 파일로 저장합니다. prebuild 때 config plugin이 `android/app/proguard-rules.pro`에 붙입니다.

#### 4. app.json 설정

아래는 Expo SDK 58 기준입니다. SDK 53·54는 「Expo SDK 버전별 차이」를 함께 확인해 주세요.

```json
{
  "expo": {
    "ios": {
      "bundleIdentifier": "com.example.app",
      "infoPlist": {
        "NSUserTrackingUsageDescription": "This identifier will be used to deliver personalized ads to you.",
        "SKAdNetworkItems": [
          { "SKAdNetworkIdentifier": "55644vm79v.skadnetwork" },
          { "SKAdNetworkIdentifier": "4fzdc2evr5.skadnetwork" }
        ],
        "NSAppTransportSecurity": { "NSAllowsArbitraryLoads": true }
      }
    },
    "android": {
      "package": "com.example.app"
    },
    "plugins": [
      [
        "expo-build-properties",
        {
          "android": {
            "kotlinVersion": "2.2.0",
            "enableMinifyInReleaseBuilds": true,
            "extraMavenRepos": [
              "https://dev-adwhale.github.io/adwhale-sdk-android-maven/maven-repo",
              "https://cauly.github.io/cauly-sdk-android-maven/maven-repo",
              "https://cauly.github.io/admize-sdk-android-maven/maven-repo",
              "https://devrepo.kakao.com/nexus/content/groups/public/"
            ]
          },
          "ios": {
            "extraPods": [
              { "name": "GoogleMobileAdsMediationPangle", "version": "~> 7.9.0.6.0" }
            ]
          }
        }
      ],
      [
        "./plugins/withAdwhale",
        {
          "androidPublisherUid": "발급받은 PUBLISHER_UID 값",
          "androidAdmobAppId": "애드웨일이 제공한 Admob APP ID값",
          "iosAdmobAppId": "애드웨일이 제공한 Admob APP ID값 (iOS)",
          "androidDependencies": [
            "net.adwhale.sdk.cauly.adapter:cauly-sdk:3.5.47.2",
            "net.adwhale.sdk.admize.adapter:admize-sdk:1.0.10.0",
            "net.adwhale.sdk.adfit.adapter:adfit-sdk:3.21.17.8",
            "net.adwhale.sdk.admob.adapter:admob-sdk:25.4.0.0",
            "net.adwhale.sdk.levelplay.adapter:levelplay-sdk:8.12.0.8"
          ],
          "proguardRulesFile": "./adwhale-proguard-rules.pro"
        }
      ]
    ]
  }
}
```

{% hint style="info" %}
* `SKAdNetworkItems`: 3.1 iOS 탭 「SKAdNetwork 구성」의 식별자 전체를 위 형식으로 넣어 주세요. 예시는 2개만 적었습니다.
* `androidDependencies`: 사용하지 않는 어댑터는 빼도 됩니다. [3.3 파트너 네트워크 연동](3.3.md)의 빌더(2.7.11)에서 나온 Android 의존성은 `'그룹:이름:버전'` 형식으로 이 배열에 추가하고, 빌더에 나온 Maven 저장소는 `extraMavenRepos`에 추가해 주세요.
* `extraPods`: 3.3 iOS 탭의 파트너 네트워크 pod 중 필요한 것만 같은 형식으로 추가해 주세요.
* `GADApplicationIdentifier`는 `ios.infoPlist`가 아니라 plugin 옵션 `iosAdmobAppId`로 넣어 주세요. Expo SDK 54 이하는 `ios.infoPlist`에 넣은 이 키를 prebuild가 지워서, 앱이 실행되자마자 종료됩니다.
{% endhint %}

#### 5. Expo SDK 버전별 차이

| 항목                 | SDK 58                         | SDK 54                                                                | SDK 53                                                                              |
| ------------------ | ------------------------------ | --------------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| Kotlin Gradle 플러그인 | `kotlinVersion: "2.2.0"`만으로 적용 | `kotlinVersion: "2.2.0"` + [3.1](3.1.md)의 `withKotlinGradlePlugin` 추가 | `kotlinVersion`을 넣지 마세요(`Key 2.2.0 is missing in the map` 오류로 빌드 실패)                |
| release 난독화 옵션     | `enableMinifyInReleaseBuilds`  | `enableMinifyInReleaseBuilds`                                         | `enableProguardInReleaseBuilds` (`enableMinifyInReleaseBuilds`는 오류 없이 무시되어 난독화가 꺼짐) |

#### 6. prebuild와 실행

```bash
npx expo prebuild --clean
npx expo run:android --variant release
npx expo run:ios
```

{% hint style="info" %}
app.json이나 config plugin을 바꾼 뒤에는 `npx expo prebuild --clean`을 다시 실행해 주세요.
{% endhint %}
